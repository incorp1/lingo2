Задача: заголовки (label) полей не должны выглядеть мельче плейсхолдеров; все
поля ввода в приложении (input / textarea / select) должны иметь единый стиль.

      для `input / textarea / select` в `css/base.css`.

      заголовки полей крупнее и насыщеннее, поля одного размера.
- [x] 3. Поля модалок и настроек (`css/stats-settings.css`, `css/polish.css`,
      `css/settings-polish.css`) переведены на те же токены.
- [x] 4. Прогнан `npm test`: 261/264. Три падения (`deck-import-language`,
      `language-model-migration`, `legacy-language-fixture`) воспроизводятся и

## Правило на будущее

Не дублировать геометрию полей в новых CSS-файлах. Нужен другой размер —
переопределять токены `--field-*` в области контейнера.
