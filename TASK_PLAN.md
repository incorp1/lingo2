## Схема данных и затрагиваемые файлы

- Новый `languages.js`: реестр en/nb, название для AI, ключ локализации, локаль en-US/nb-NO, поддержка словаря и адаптерные коды переводчиков. Подключение до потребителей, включение в APP_SHELL.
- `state.decks` и `state.cards` содержат все языки; язык хранится только в `deck.learningLanguage`, карточка получает его через колоду. Глобальная уникальность ID и проверка ссылок обязательны.
- Версия модели данных вводится отдельно от версии приложения, IndexedDB и формата копии. `state.activeLearningLanguage`; `state.languageProfiles[code]` с activeDeckId, history, streak, sessionReviewedIds, practiceDraft, studyResume. Профили — единственное каноническое место хранения этих данных.
- Общие studyCycles по ID карточек, общие настройки, язык интерфейса и AI-ключ; practiceHistory и reviewEvents получают learningLanguage, лимит истории действует отдельно по языкам.
- IndexedDB: прежние `lingo-cards`, версия 3, `lingo-cards-v1`; без изменения stores/indexes версия БД не повышается.
- Основные файлы: `js/state.js`, `storage.js`, `backup.js`, `js/import-export.js`, `js/settings.js`, `index.html`, `js/scheduler.js`, `js/study.js`, `js/decks.js`, `js/cards.js`, `js/stats.js`, `ai.js`, `js/ai-practice.js`, `js/selection.js`, `js/app-shell.js`, при необходимости `js/ui.js` и `js/edge-menu.js`, `i18n/{ru,uk,en}.js`, профильные тесты и релизные файлы.
